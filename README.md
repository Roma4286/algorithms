# Algorithms & Data Structures

A study repository for learning algorithms and data structures in Python. Here I follow a structured learning plan: from basic techniques (two pointers, sliding window, prefix sums) to graphs, greedy algorithms, backtracking, and dynamic programming.

## Project Goal

- Understand how classic data structures work by implementing them from scratch (stack, queue, linked lists, hash table, trees, heap, graph).
- Reinforce theory by solving LeetCode problems, written as files in this repository.
- Build a personal reference of patterns and solutions for technical interview prep.

## Repository Structure

- `src/data_structures/` — data structure implementations (e.g. `stack.py`, `queue.py`, `bst.py`, `min_heap.py`, `graph.py`).
- `src/algorithms/` — algorithmic techniques and problems by topic (`two_pointers`, `sliding_window`, `sorting`, `searching`, `recursion`, `greedy`, `backtracking`, `dynamic_programming`, etc.).
