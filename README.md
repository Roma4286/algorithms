# Algorithms & Data Structures (TypeScript)

A study repository for learning algorithms and data structures in TypeScript. Here I follow a structured learning plan: from basic techniques (two pointers, sliding window, prefix sums) to graphs, greedy algorithms, backtracking, and dynamic programming.

## Project Goal

- Understand how classic data structures work by implementing them from scratch (stack, queue, linked lists, hash table, trees, heap, graph).
- Reinforce theory by solving LeetCode problems, written as files in this repository.
- Build a personal reference of patterns and solutions for technical interview prep.

## Repository Structure

- `src/data-structures/` — data structure implementations (e.g. `Stack.ts`, `Queue.ts`, `BST.ts`, `MinHeap.ts`, `Graph.ts`).
- `src/algorithms/` — algorithmic techniques and problems by topic (`two-pointers`, `sliding-window`, `sorting`, `searching`, `recursion`, `greedy`, `backtracking`, `dynamic-programming`, etc.).
- Each problem is a separate file with a sample call at the bottom, run via `npx tsx src/...`.
